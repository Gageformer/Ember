Before you start

You need

  • A PS2 that can run homebrew.
  • A USB stick. Other storage like MMCE or HDD works too.
  • A PS1 BIOS file from your own console, named bios.bin. Ember does not include one.
  • Your games as .cue and .bin files.

Setup

Five steps

  1. Make a folder

    On your USB stick, make a folder called EMBER.

  2. Add Ember

    Put ember.elf and launcher.elf inside.

  3. Add your BIOS

    Put bios.bin in the same folder.

    The name must be exactly bios.bin. Rename your file if it is called something else.

  4. Add your games

    Make a games folder. Inside it, make one folder for each game. Name them how you like.

  5. Play

    Plug the stick into your PS2 and start launcher.elf from your homebrew app. Pick a game.

    Start launcher.elf, not ember.elf. Starting ember.elf only shows the PS1 menu.

Check

It should look like this

EMBER/
├── ember.elf
├── launcher.elf
├── bios.bin              you add this
└── games/
    ├── Spyro/
    │   ├── Spyro.cue
    │   └── Spyro.bin
    └── Crash Bandicoot/
        ├── Crash Bandicoot.cue
        └── Crash Bandicoot.bin

Saves show up later as MC1.vmc and MC2.vmc inside each game folder. Ember makes them for you.

The launcher

Launcher in a different place?

Next to ember.elf, the launcher needs no setup. It works from USB, MMCE, MX4SIO or HDD.

Keeping it somewhere else? Put ember-launcher.cfg beside the launcher. Open it in a text editor and remove the # from the line for your device.

ember=mass:/EMBER/        USB
ember=mmce?:/EMBER/       MMCE
ember=ata:/EMBER/         internal HDD, exFAT

The line points at the folder that holds ember.elf. Keep that folder named EMBER, so every launcher knows where to look.
