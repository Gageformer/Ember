Help

Not working?

Find your problem below. Most fixes take one minute.

Starting a game

It will not start

I see the PS1 menu, not my game

This is the most common problem. There are two usual reasons.

1. You started ember.elf.

On its own, ember.elf does not know which game to play. Start launcher.elf instead, or use another launcher.

2. You renamed the game files.

A .cue file has the name of its .bin file written inside it. If you rename the files, the name inside is now wrong.

Open the .cue in Notepad and make the name match:

wrong, this is the old name
FILE "Spyro (USA).bin" BINARY

right, same as the file
FILE "Spyro.bin" BINARY

Also check that each game has its own folder inside games.

Black screen

  • Your BIOS file must be named exactly bios.bin and sit next to ember.elf.
  • If you set display: 480p, you may need a component cable or HDMI adapter. If not, change it to display: 480.
  • If you set display: 240, some TVs can't show it. Change it to display: 480.
  • Using your own launcher? It must not reset the IOP before it starts Ember.

The launcher shows no games

The launcher that comes with Ember only works from USB. For HDD, MMCE or other storage, use one of the other launchers.

While playing

Something is wrong in the game

The controller does nothing

Analog mode is on, but the game does not support it. Press the ANALOG button to turn it off.

The analog stick does not work

Press the ANALOG button first. Some games support analog but do not turn it on by themselves.

To have it on every time, add controller: analog to that game's settings.

Old game with no analog at all? Use controller: d2a. The left stick will act as the d-pad.

The sound stutters

This is a known bug. A fix is coming in the next version.

The game freezes

Some games still do this. Please report it so it can be fixed.

Where are my saves?

In the game's folder, as MC1.vmc and MC2.vmc. To back up a game, copy its folder.

Settings

How to change a setting

Make a text file called settings.txt next to ember.elf. Write one setting on each line.

display: 480
controller: auto

Want a setting for one game only? Put a settings.txt in that game's folder. All settings work there except display.

SettingOptionsWhat it does
display480, 240, 480pVideo mode. 480 works on almost every TV. 240 is best on a CRT.
timingauto, ntsc, palThe game's speed clock. Auto follows the game's region.
controllerauto, analog, d2aHow the pad starts. Best set for each game.
ditheron, offThe PS1 dot pattern. On is native, off may look smoother.
shading15, 2424 gives smoother colour. Some games utilize the quirks of 15-bit.

The option in bold is the normal one. To go back to normal, delete the line or the file.
