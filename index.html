How it works

Why it is fast

The PS2 shares many similarities with the PS1. Ember utilizes that.

It translates

PS1 code is compiled directly into PS2 code.

Both consoles use MIPS processors, so the JIT has very little to convert. Each block is compiled once, then reused.

Hardware accelerated

Graphics, sound and memory inline to the PS2's own hardware where it can.

The PS2's graphics and sound chips do that work natively, leaving the main CPU free for the game.

Direct memory

The PS1's memory map is laid onto the PS2's own memory manager, the MMU.

A PS1 read or write runs as a native PS2 one, with no software lookup in between. The PS1's mirrored memory regions come from the same mapping.

And it still stays exact

None of this trades accuracy for speed. The PS1's 3D math is reproduced exactly, down to the rounding quirks games depend on, so games look the way they should.
