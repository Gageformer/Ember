For developers

Make your own launcher

Any app that can start an ELF with an argument can start Ember. The argument is the game's folder name.

ember.elf Spyro                      plays games/Spyro/
ember.elf "Crash Bandicoot (USA)"    spaces are fine
ember.elf "Spyro/Spyro.cue"          pick one file
  • Pass the full path to ember.elf as the first argument.
  • Do not reset the IOP. Ember uses the storage drivers your app already loaded.
  • No permission needed. Just keep the credit.

More detail is in the README. Made something? Tell me and I'll add it here.
